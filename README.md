🔐 What is Caesar Cipher?
The Caesar Cipher is a basic encryption technique where each letter in the plaintext is shifted a certain number of places down or up the alphabet.

Features
🔄 Encrypt & Decrypt messages

🔢 Custom Shift Value (e.g., shift by 3)

🔤 Custom Alphabet Support

🔡 Handles both Uppercase and Lowercase

🎨 Responsive UI (works on mobile & desktop)

🧹 Clear/Reset button for quick input reset

⚙️ Input validations and real-time results
